# Dataset Organizer

Инструмент для парсинга и организации данных мониторинга процесса WAAM.

Принимает CSV датасет с данными собранными в процессе печати и раскладывает его
по файловой структуре в соответствии с источником данных (координаты, сварка, сканер и т.д.).

Реализован в виде Google Colab блокнота для удобства запуска без установки зависимостей.

## `2. Парсинг`

<img width="507" height="374" alt="image" src="https://github.com/user-attachments/assets/1f8933e2-531c-4a8f-a66e-c5957ff6a92c" />

- CUSTOM_DATA_PATH - Параметр содержащий путь к файлу датасета.<br/>
**! Необходим только в случае ручной загрузки датасета !**
- **CUSTOM_NAME** - Кастомное имя программы. По умолчанию используется первое значение поля jbi_name. 
- **OUTPUT_PATH** - Путь к папке, где куда будет сохранён результат парсинга. По умолчанию сохраняет в папку processed_data.
- **STRIP_PREFIXES** - Если активно, при сохранении результата парсинга из названий колонок таблиц будут удалена часть отсылающая к их источнику. Например "control_", "io_", "weldind" и т.п..

> [!NOTE]
> Вы можете сохранять результат сразу в ваш гугл диск, если он был ранее подключён. <br/>
> Для этого установите в "OUTPUT_PATH" подобное значение: <br/>
> "drive/MyDrive/output_folder_name"

## `3. Скачивание результата`

<img width="683" height="256" alt="image" src="https://github.com/user-attachments/assets/61a2706b-5a63-46cc-b4b3-e213660e08a6" />

> [!WARNING]
> Результат всегда берётся по пути указанному в "OUTPUT_PATH" из блока парсинга.
> При изменении значения "OUTPUT_PATH" **после** парсига, этот блок не сможет найти результат.

### download_type:
- **Архив** - Скачает архив с результатом.
- **Архив в Colab** - Cохраняет результат в сжатом виде в файловой системе Colab.
- **Google Drive** - Cохраняет результат на ваш гугл диске по указанному в "DRIVE_PATH" пути.

### DRIVE_PATH - 
Путь по которому будет сохранён результат при выборе варианта скачивания "Google Drive".
Можно оставить пустым, что сохранит результат напрямую на диск, или указать название папки или несколько вложенных папок ("folder1/folder2")

> [!TIP]
> Через "OUTPUT_PATH" в блоке парсинга можно настроит сохранение напрямую в гугл диск, без промежуточного сохранения в файловой системе Colab
